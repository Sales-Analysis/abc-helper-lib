## Page Model

The documentation is split into:

- overview pages for entry points and navigation;
- decision-guide pages for analysis selection;
- domain index pages for inventory and customer analytics;
- one dedicated page per analysis;
- technical reference pages for API conventions, compatibility, defaults, and edge cases.
