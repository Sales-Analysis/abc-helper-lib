# FSN

Назад к [товарным анализам](../inventory.md)

## Назначение

FSN классифицирует товары по частоте движения по периодам.

## Когда использовать

- когда нужно разделить fast-moving, slow-moving и non-moving позиции;
- когда история движения важнее вклада в выручку.

## Когда не использовать

- когда важна только вариативность спроса;
- когда история движения слишком короткая или не периодическая.

## Вход

- `SKU`, `Name`
- `Movements []float64`
- опциональные пороги `FastMinActivityRate`, `SlowMinActivityRate`

## Выход

- `Periods`
- `ActivePeriods`
- `ActivityRate`
- `TotalMovement`
- `AverageMovement`
- `LastMovementPeriod`
- `Group` в `F/S/N`

## Правила

- активными считаются периоды с движением больше нуля
- `ActivityRate = ActivePeriods / Periods * 100`
- дефолтные пороги: `F >= 70%`, `S >= 1%`, иначе `N`
- товары без активных периодов всегда попадают в `N`

## Пример

```go
out, err := analytics.New().Inventory().FSN(ctx, fsn.Input{
    Items: []fsn.Item{
        {SKU: "A", Name: "Item A", Movements: []float64{3, 0, 2, 1}},
    },
})
```

## Интерпретация

`F` часто движется, `S` движется эпизодически, `N` фактически не двигается на
выбранном горизонте.

## Частые ошибки

- путать activity rate с объемом движения;
- считать, что разовый крупный пик автоматически делает товар `F`.
