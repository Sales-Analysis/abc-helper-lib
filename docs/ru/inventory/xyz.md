# XYZ

Назад к [товарным анализам](../inventory.md)

## Назначение

XYZ классифицирует товары по вариативности спроса через коэффициент вариации.

## Когда использовать

- когда пополнение зависит от стабильности спроса;
- когда нужно отделить предсказуемый спрос от волатильного;
- как ось вариативности для [ABC-XYZ](abcxyz.md).

## Когда не использовать

- когда важнее вклад в выручку, а не поведение спроса;
- когда нет периодического ряда спроса.

## Вход

- `SKU`, `Name`
- `Demands []float64`
- опциональные пороги `XMaxCV`, `YMaxCV`

## Выход

- `Periods`
- `AverageDemand`
- `StandardDeviation`
- `CoefficientOfVariation`
- `Group` в `X/Y/Z`

## Правила

- по ряду спроса считаются среднее и стандартное отклонение
- `CoefficientOfVariation = StandardDeviation / AverageDemand * 100`
- дефолтные пороги: `X <= 10`, `Y <= 25`, иначе `Z`
- пустой ряд спроса или нулевой средний спрос попадает в `Z`

## Пример

```go
out, err := analytics.New().Inventory().XYZ(ctx, xyz.Input{
    Items: []xyz.Item{
        {SKU: "A", Name: "Item A", Demands: []float64{10, 12, 9}},
    },
})
```

## Интерпретация

`X` — самый стабильный спрос, `Y` — умеренная вариативность, `Z` — высокая
вариативность или фактическое отсутствие спроса.

## Частые ошибки

- передавать суммы продаж вместо периодических значений спроса;
- забывать, что пороги CV выражаются в процентах;
- читать `Z` как “плохой товар”, хотя он может быть просто неактивным.
