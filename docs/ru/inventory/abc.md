# ABC

Назад к [товарным анализам](../inventory.md)

## Назначение

ABC классифицирует товары по вкладу в выручку после сортировки по сумме продаж.

## Когда использовать

- когда нужно выделить SKU с максимальным вкладом в выручку;
- когда приоритет ассортимента зависит от contribution, а не от частоты движения;
- как value-ось для [ABC-XYZ](abcxyz.md).

## Когда не использовать

- когда важнее стабильность спроса, а не концентрация выручки;
- когда группировка должна строиться по критичности или unit cost.

## Вход

- `SKU`, `Name`
- `Quantity`
- `Price`
- опциональные пороги `AMaxShare`, `BMaxShare`

## Выход

- `PriceTotal`
- `ShareTotal`
- `ShareAccumulated`
- `Group` в `A/B/C`
- `TotalRevenue`

## Правила

- `PriceTotal = Quantity * Price`
- товары сортируются по `PriceTotal` по убыванию
- `ShareTotal = PriceTotal / TotalRevenue * 100`
- `ShareAccumulated` считается накопительно в отсортированном порядке
- дефолтные пороги: `A <= 80%`, `B <= 95%`, иначе `C`

## Пример

```go
out, err := analytics.New().Inventory().ABC(ctx, abc.Input{
    Products: []abc.Product{
        {SKU: "A", Name: "Item A", Quantity: 10, Price: 100},
        {SKU: "B", Name: "Item B", Quantity: 5, Price: 50},
    },
})
```

## Интерпретация

`A`-товары дают основной вклад в выручку. `B` важны, но вторичны. `C` имеют
минимальный вклад в рамках выбранных порогов.

## Частые ошибки

- путать цену за единицу и общую выручку;
- ожидать, что порядок результата совпадет с порядком входа;
- пытаться читать из ABC стабильность спроса.
