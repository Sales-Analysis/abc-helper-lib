# SDE

Назад к [товарным анализам](../inventory.md)

## Назначение

SDE классифицирует товары по сложности снабжения через lead time.

## Когда использовать

- когда supply difficulty важнее спроса или value;
- когда нужна простая сегментация по lead time.

## Когда не использовать

- когда lead time нестабилен и не укладывается в одну метрику;
- когда сложность снабжения определяется факторами, которых нет во входе.

## Вход

- `SKU`, `Name`
- `LeadTimeDays`
- опциональные пороги `ScarceMinLeadTime`, `DifficultMinLeadTime`

## Выход

- `LeadTimeDays`
- `Group` в `S/D/E`

## Правила

- если пороги не заданы, они выводятся из распределения lead time
- результаты сортируются по `LeadTimeDays` по убыванию
- самые длинные lead time попадают в `S`, затем `D`, затем `E`

## Пример

```go
out, err := analytics.New().Inventory().SDE(ctx, sde.Input{
    Items: []sde.Item{
        {SKU: "A", Name: "Item A", LeadTimeDays: 45},
    },
})
```

## Интерпретация

`S` — самые сложные для снабжения товары, `D` — умеренно сложные, `E` —
самые простые в рамках текущих порогов.

## Частые ошибки

- путать SDE с метрикой service level;
- сравнивать группы между разными датасетами без фиксированных порогов.
