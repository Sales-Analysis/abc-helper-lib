# HML

Назад к [товарным анализам](../inventory.md)

## Назначение

HML классифицирует товары по unit cost.

## Когда использовать

- когда cost intensity важна для политики запасов;
- когда нужна быстрая сегментация по стоимости без weighting по выручке.

## Когда не использовать

- когда total contribution важнее unit cost;
- когда unit cost несопоставим между товарами.

## Вход

- `SKU`, `Name`
- `UnitCost`
- опциональные пороги `HighMinUnitCost`, `MediumMinUnitCost`

## Выход

- `UnitCost`
- `Group` в `H/M/L`

## Правила

- если пороги не заданы, они выводятся из отсортированного набора данных
- реализация делит unit cost на три диапазона
- результаты сортируются по `UnitCost` по убыванию

## Пример

```go
out, err := analytics.New().Inventory().HML(ctx, hml.Input{
    Items: []hml.Item{
        {SKU: "A", Name: "Item A", UnitCost: 250},
    },
})
```

## Интерпретация

`H` — самые дорогие на единицу, `M` — средний диапазон, `L` — самые дешевые.

## Частые ошибки

- считать HML эквивалентом ABC по value;
- забывать, что авто-пороги зависят от состава текущего набора данных.
