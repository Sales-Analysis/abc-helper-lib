# VED

Назад к [товарным анализам](../inventory.md)

## Назначение

VED классифицирует товары по операционной критичности.

## Когда использовать

- когда влияние stockout важнее value или вариативности спроса;
- когда закупочная или медицинская политика зависит от criticality.

## Когда не использовать

- когда нет содержательного score критичности;
- когда score не сопоставим между товарами.

## Вход

- `SKU`, `Name`
- `CriticalityScore`
- опциональные пороги `VitalMinScore`, `EssentialMinScore`

## Выход

- `CriticalityScore`
- `Group` в `V/E/D`

## Правила

- дефолтные пороги: `V >= 70`, `E >= 40`, иначе `D`
- результаты сортируются по `CriticalityScore` по убыванию

## Пример

```go
out, err := analytics.New().Inventory().VED(ctx, ved.Input{
    Items: []ved.Item{
        {SKU: "A", Name: "Item A", CriticalityScore: 85},
    },
})
```

## Интерпретация

`V` — самые критичные товары, `E` — важные, но не vital, `D` — наименее
критичные в рамках выбранной шкалы.

## Частые ошибки

- использовать произвольный score без бизнес-смысла;
- ожидать, что пакет выведет criticality из других полей.
